# Greek Mythology Educational Adventure Game [![eng](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/cbalampa/Educational-Game/blob/main/README.md)

A Unity-based educational 3rd person Action/Adventure game inspired by Greek mythology.

The project combines exploration, NPC interaction, quizzes, and gameplay challenges into an interactive learning experience. The player explores a mythology-themed world, completes trials inspired by Greek gods and legends, collects rewards, and learns historical and mythological information through gameplay.

This project was developed as part of an academic thesis focused on exploring how video games can be used as educational tools while following a development process similar to commercial game production.

## ✨ Key Features

### Exploration-Based Hub World

The player begins in a central mythology-inspired world that acts as the main area of progression.

The Hub World allows the player to:

- Explore the environment
- Discover Greek mythology references
- Interact with NPC characters
- Access different challenges
- Collect information needed to progress through the game

### NPC Interaction

Characters throughout the world guide the player through quizes, challenges, and mythology-related stories.

The game uses NPC interactions to:

- Introduce challenges
- Provide educational information
- Progress the narrative
- Encourage exploration

### Mythology-Based Trials

The game includes multiple challenges inspired by Greek mythology, each introducing different gameplay mechanics.

### Trial of Ares

A combat-inspired challenge focused on platforming.

Features:

- Third-person gameplay
- Obstacle avoidance
- Coin collection objectives
- Respawn mechanics after failure

### Educational Gameplay Design

The project focuses on combining learning with entertainment by integrating mythology knowledge into gameplay mechanics.

Players learn through:

- Environmental exploration

- Interactive objects
- Quiz challenges

## 🔄 Application Flow

1. The player launches the game and starts from the Main Menu.
2. The player enters the Hub World, the central area where exploration, progression, and interaction take place.
3. The player explores the environment and interacts with NPC characters to discover mythology-related information, take on challenges, and progress through the game.
4. The player completes different mythology-inspired trials, each featuring unique gameplay mechanics such as obstacle navigation, archery, quizzes, and flying challenges.
5. Successful completion of trials rewards the player with in-game currency and progression updates.
6. The player can use collected rewards in the in-game shop to unlock additional items and information that assist with future challenges.
7. Through exploration, storytelling, and interactive challenges, the player learns about Greek mythology while progressing through the game.

## 🚀 Getting Started

2. Extract the archive.
3. Open the extracted folder.
4. Run the game executable (`.exe`).

- Operating System: Windows
- No additional installation is required.
